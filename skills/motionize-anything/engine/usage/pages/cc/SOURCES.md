# 터미널 그림 출처

## cc-best@2x.png
- 원본: https://raw.githubusercontent.com/anthropics/claude-code/main/demo.gif (github.com/anthropics/claude-code README 의 demo.gif, 1552x992)
- 만든 법: 프레임 0(타이핑 시작 화면)에서 입력 줄에 쓰인 글을 배경색으로 지우고 커서 블록만 남겼다. `cc-best@2x.png` 는 그 그림을 Lanczos 로 2배(3104x1984) 키운 것이다(새 정보는 없다).
- 고른 까닭: 환영 상자(Claude Code 버전, 모델, 경로)와 빈 입력 줄 `>`, 고정폭 글꼴, 대화 없음, 어두운 단일 테마다.
- 입력 줄(원본 그림 px): 위 구분선 y=322, 아래 구분선 y=398. 줄 사각형 x=54..1495, y=324..397. `>` 는 x=57~71, 글 시작 x=90, 글자 폭 18px(고정폭), 글자 높이 약 34px(y=343..377)다.
- 색: 배경 rgb(0,43,54), 글자 rgb(123,148,155), 커서 블록 rgb(128,147,150), 구분선 rgb(60,91,103).
- 창 바깥은 macOS 바탕화면 그라데이션과 흰 제목줄(y=50..106), 둥근 창(x=44..1504, y=50..952)이다.
- 그림 속 경로와 창 제목은 `index.html` 이 그 위에 덮어 그린다(`#ccPath`, `#ccTitle`).
- 밝은 테마의 공식 정지 그림은 찾지 못했다.
