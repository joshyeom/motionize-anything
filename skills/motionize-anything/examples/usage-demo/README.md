# 메모 앱 사용법 모션 예시

가짜 메모 앱을 HTML 로 그려 사용법 모션의 모든 기능을 한 번씩 쓰는 완성 예시입니다. 엔진 파일은 `engine/usage/` 에서 복사했고 `index.html` 과 `motion-steps.js` 의 `[기능마다]` 부분만 채웠습니다.

## 여는 법

```bash
cd <이 폴더>
python3 -m http.server 8975 --bind 127.0.0.1
```

| 주소 | 보기 |
|------|------|
| `http://127.0.0.1:8975/index.html` | 발표 모드. 클릭, 오른쪽 화살표, Space, Enter 로 넘기고 왼쪽 화살표로 돌아갑니다. |
| `http://127.0.0.1:8975/index.html?auto=1` | 자동 전환을 켠 채로 엽니다. |
| `http://127.0.0.1:8975/index.html?box=1` | 1024x576 으로 반복 재생합니다. |
| `http://127.0.0.1:8975/index.html?export=1` | 조작 요소 없이 원래 시간표로 그립니다. mp4 내보내기가 씁니다. |

## 장면표

길이는 약 40초이고 멈춤은 7개입니다.

| 장면 | 칩 | 하는 일 | 쓰는 기능 |
|------|-----|---------|-----------|
| 1 | 메모 만들기 | 새 메모를 누르고 제목을 입력해 저장합니다. | 클릭, 흰색 거치기 전환, 입력, 스낵바 |
| 2 | 목록 확인 | 새 메모 항목을 강조하고 문제 박스를 띄웁니다. | 강조 테두리, 문제 박스 |
| 3 | 에이전트에게 맡기기 | 터미널로 넘어가 요청을 입력하고 응답을 받은 뒤 앱으로 돌아옵니다. | 창 바꾸기 슬라이드, 터미널 입력, Enter, 응답 줄, 처음으로 돌아가기 |

## 그린 것

- 앱 화면은 모두 daisyUI 컴포넌트(`mockup-window`, `menu`, `navbar`, `list`, `btn`, `input`, `textarea`, `alert`)입니다. 캡처 이미지는 쓰지 않았습니다. 색은 `ui.css` 의 daisyUI 테마 하나가 정합니다.
- 터미널 장면은 `pages/cc/cc-best@2x.png` 위에 경로, 제목, 입력, 응답 글을 덮어 그렸습니다. 덮개는 daisyUI `mockup-code` 이고 색은 그림의 색에 맞춘 테마 변수(`--color-term-*`)입니다.

## 뺀 것, 실제와 다른 점

- 메모 앱은 이 예시를 위해 만든 가짜 화면입니다. 실제 제품이 아닙니다.
- 문제 박스의 내용("제목을 비워도 저장됩니다")은 문제 박스 모양을 보이기 위한 가짜 문장입니다.
- 터미널 그림 속 환영 문구는 공개된 Claude Code 소개 영상의 프레임입니다(출처는 `pages/cc/SOURCES.md`).

## 확인한 것

- 127.0.0.1 서버에서 열었을 때 페이지 오류 0건, 콘솔 오류는 `motion-params.json` 404 한 줄입니다.
- 칩 3개가 모두 760px 안에 한 줄로 들어갑니다.
- `baseline.mjs` 로 기준 프레임을 저장했습니다.
