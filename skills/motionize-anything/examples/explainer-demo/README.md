# 문서 검색 도구 진행 상황 설명 모션 예시

사내 문서 검색 도구를 만드는 가상 프로젝트의 진행 상황을 설명하는 완성 예시입니다. 실제 기업, 제품, 인물과 관계가 없고 숫자도 모두 지어낸 값입니다.
설명 모션의 화면 디자인 기준입니다. 새 설명 모션은 이 예시의 장면 파일에서 색, 칸 모양, 큰 숫자, 단계(`steps`), 박스 흐름, 끝 화면을 가져다 씁니다.

## 여는 법

```bash
cd <이 폴더>
python3 -m http.server 8997 --bind 127.0.0.1
```

- 주소는 `http://127.0.0.1:8997/index.html` 입니다.
- 무대를 클릭하거나 오른쪽 화살표, Enter, Space 를 누르면 다음 멈춤으로 넘어갑니다. 왼쪽 화살표는 이전 멈춤입니다.
- 마지막 멈춤에서 한 번 더 넘기면 "끝" 화면이 나오고, 이전을 누르면 마지막 컷으로 돌아옵니다.
- 콘솔 오류는 `motion-params.json` 404 한 줄뿐입니다.

## 장면표

장면은 5개이고 컷(읽는 멈춤)은 12개입니다.

| 장면 | 칩 | 자막 |
|---|---|---|
| 1 | 지금, 어디까지 왔나요 | 검색 도구는 작업 단계 수로 92%까지 왔습니다 |
| 1 |  | 작업 목록에서 남은 일은 완료 확인 2개와 단계 밖 판단 2개입니다 |
| 2 | 하는 일, 이 도구는 무엇을 하나요 | 문서가 바뀌면 에이전트가 색인과 검색 화면을 차례로 고칩니다 |
| 2 |  | 고친 검색 화면을 기준 화면과 비교해 차이를 보고합니다 |
| 3 | 실제 실행, 처음부터 끝까지 돌려 봤나요 | 문서 변경 1건으로 끝까지 돌려 대조 대상 15쌍 중 14쌍이 반영됐습니다 |
| 3 |  | 검사에서 모바일 앱 테스트를 제외한 1곳 때문에 완료 판단을 다시 해야 합니다 |
| 4 | 검색 화면, 기준 화면과 얼마나 같아졌나요 | 최신 빌드에서 다시 측정해도 같은 원인의 차이 17종류 중 15종류가 사라진 상태입니다 |
| 4 |  | 그래도 기준 화면과 같은 화면은 측정한 화면 50개 중 아직 0개입니다 |
| 4 |  | 50개 중 2개는 안내 배너 하나만 걸린 화면입니다 |
| 5 | 남은 것, 보고서까지 무엇이 남았나요 | 화면 50개를 3번 측정하고 판정까지 마쳤습니다 |
| 5 |  | 전체 보고서는 남은 단계 7개 중 6개를 마쳐야 나옵니다 |
| 5 |  | 보고서가 나오면 완료 확인 2개를 하고 단계 밖 판단 2개를 정합니다 |

끝 화면은 마지막 컷에서 한 번 더 누르면 나오고 "끝" 한 글자입니다.

## 이 예시가 보여 주는 디자인 요소

| 요소 | 나오는 곳 |
|---|---|
| 초점 채움과 DIM | 모든 컷, 초점 하나만 초점 색(`blue`, `green`, `yellow`) 채움이고 그 밖의 요소는 `kit.DIM`(0.45) 또는 흰 바탕 윤곽 |
| 자막 하이라이트 | 모든 컷, 핵심 낱말에 초점 색 계열의 하이라이트 색(`--color-mark-*`) |
| 큰 숫자 | 장면 1의 92%, 장면 3의 14 / 15, 장면 4의 15 / 17 |
| 진행 칸 | 장면 1의 단계 칸 26개, 장면 3의 칸 15개, 장면 4의 칸 17개 |
| 단계 | 장면 3의 daisyUI `steps` 4개와 노랑 느낌표 |
| 박스 흐름 | 장면 2의 박스 3개, 장면 5의 다음 할 일 박스 3개 |
| 화면 칸 격자 | 장면 4의 화면 칸 50개와 숫자 박스 |
| 단계 박스 격자 | 장면 5의 단계 박스 14개(마침, 건너뜀, 남음) |
| 끝 화면 | 마지막 컷 다음의 "끝" |

## 그린 것

- 박스, 칸, 화살표, 숫자, 자막은 모두 `scenes/kit.js` 부품이 daisyUI 컴포넌트(`alert`, `stat`, `steps`, `skeleton`, `badge`)로 그렸습니다. 색은 `ui.css` 의 daisyUI 테마 하나가 정합니다.
- 장면 2의 화면 2장 그림은 `assets/s2-screen.png` 입니다. 글자와 로고가 없는 회색 도형 그림입니다.

## 실제와 다른 점

- 기업, 제품, 숫자, 문장이 모두 가상입니다.
- 장면 4의 화면 칸 배치는 어떤 화면과도 대응하지 않습니다.
