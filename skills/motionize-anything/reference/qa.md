# 확인 (QA)

## 1. 기준 프레임 비교 (기본값 그림이 바뀌지 않았나)

엔진이나 단계 표를 고치기 전에 프레임을 찍어 두고, 고친 뒤 다시 찍어 픽셀로 비교한다.

```bash
node <영상 폴더>/baseline.mjs /tmp/guide_base 8975    # 고치기 전
node <영상 폴더>/baseline.mjs /tmp/guide_new  8975    # 고친 뒤
python3 -c "
from PIL import Image; import numpy as np, glob, os
print(max(np.abs(np.asarray(Image.open(f).convert('RGB')).astype(int)-np.asarray(Image.open('/tmp/guide_new/'+os.path.basename(f)).convert('RGB')).astype(int)).max() for f in glob.glob('/tmp/guide_base/*.png')))"
```

- `baseline.mjs` 는 1920×1080, 픽셀 배율 1로 `?export=1` 을 열어 0초, 단계마다 `keyMoment` 순간, 끝 직전(DURATION − 0.01)을 `f_<초>.png` 로 저장하고 `DURATION`, 프레임 수, 오류를 출력한다.
- 포트 인자 기본값은 8947 이다. 서버가 떠 있어야 한다.
- 통과: 최대 차이 0. 의도한 변경이면 바뀐 프레임만 눈으로 확인한다.
- 단계 수나 길이가 바뀌면 프레임 시각이 달라져 파일 이름이 맞지 않는다. 그때는 `baseline.mjs` 의 시각 계산을 고정 시각 목록으로 바꾼 임시 복사본을 영상 폴더 안에 두고(예: `<영상 폴더>/baseline-fixed.mjs`, 끝나면 지움) 전후를 찍는다. `/tmp` 에 두면 위 폴더에서 Playwright를 찾지 못해 실패한다. 목록: 장면 정지, 클릭 +0.15초, 입력 중간, 전환 중간, 강조 가운데, 끝.
- 이 비교에는 Pillow 와 numpy 가 필요하다. Playwright 준비는 `reference/usage.md` 의 Playwright 준비 절을 따른다.

## 2. 발표 모드 확인

- 서버 주소를 브라우저(Aside 를 쓰면 `aside repl` 의 `openTab`)로 연다. 1920×1080 창과 그보다 작은 창(예: 1600×900)에서 본다.
- `window.stops().length` 가 장면표의 멈춤 수(장면마다 문장 2개 + 문제 박스 수)와 같은지 확인한다.
- 처음부터 끝까지 클릭으로 넘기며 멈춤마다 화면을 찍어 본다. 칩, 문장, 문제 박스가 다 나타난 상태로 멈춰야 한다.
- 멈춤 시작과 끝 화면을 찍어 비교한다. 같아야 넘길 때 화면이 튀지 않는다(글자 가장자리 차이 정도만 허용).
- 조작: →, Enter, Space 는 다음, ←와 [이전] 은 이전, 자동 전환을 켜면 멈추지 않음, 마지막 멈춤에서 다음을 누르면 첫 멈춤(1 / 전체)으로 돌아옴
- 창 가운데 정렬: 무대 위와 아래의 남는 높이가 같은지 본다(`#wrap` 의 marginTop 이 `(innerHeight-1080*k)/2`).
- 칩(760px), 문장(1680px, 한 줄), 앱 창, 문제 박스가 서로 겹치지 않는지 본다.

## 3. 눈으로 보기

- 발표 모드와 `?box=1`(1024×576) 둘 다 본다.
- 장면마다 대표 프레임을 한 장에 붙여 본다.
- 볼 것
  - 잘림 없음, 칩이 760px 안에 한 줄
  - 물방울이 대상 가운데에 뜸
  - 흰색 거치기가 지정한 사각형 안에서만 일어남, 두 창이 겹치는 순간 없음
  - 그린 요소(포커스 테두리, 캐럿, 덮개)가 캡처와 같은 위치, 크기, 색
  - 입력 글자 속도와 읽는 멈춤(1.6초 이상)
  - 0초와 끝 프레임이 같은 상태
  - 콘솔 오류 없음. `motion-params.json` 404 한 줄은 정상

## 4. ?box=1 가독성

- `?box=1` 은 0.533배라 본문 13~14px 글자가 7~8px 이 된다.
- 레티나(픽셀 배율 2) 화면에서는 작은 글까지 읽힌다. 1배 화면에서는 작은 글이 흐리다.
- 작은 자리에 넣을 때는 1440p 파일을 쓰는 편이 낫다.
